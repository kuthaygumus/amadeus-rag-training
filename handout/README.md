# Handout

The two things that leave the room in writing.

| file | who reads it, and when |
|---|---|
| `pre-work-email-tr.md` | sent three days before the day; gets a laptop from nothing to `READY` |
| `handout-tr.md` | printed and handed out; read a week later, on a Monday, with no site open |

Both are Turkish, because the room is. Commands, filenames and model names stay English.

`handout-tr.md` has to stand on its own: the gate chain with the site's module numbers, the
measured tables, the decision rubrics, the commands from `git clone` to a running benchmark, and
the repository and site URLs. Anyone reading it should be able to rebuild the day's environment
without the site. Every number in it comes from a run — when the corpus or the code moves, the
tables here move with them.

Helios Air is a fictional airline. The corpus is synthetic training material; no Amadeus system,
customer or production data appears anywhere in this repository.
