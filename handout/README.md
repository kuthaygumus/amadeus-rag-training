# Handout

The two things that leave the room in writing.

| file | who reads it, and when |
|---|---|
| `pre-work-email-tr.md` | sent three days before the day; gets a laptop from nothing to `READY` |
| `handout-tr.md` | printed and handed out; read a week later, on a Monday, with no site open |

Both are Turkish, because the room is. Commands, filenames and model names stay English.

**`handout-tr.md` opens with a trainer-only block — the presenter-mode shortcut — that ends at the
first `---`. Delete it before printing the room copies.** It is there because the trainer will not
have the repository `README.md` open at 09:00 on 7 October, and the site deliberately offers no
visible control that would reveal presenter mode to a participant.

Everything after that block has to stand on its own: the gate chain with the site's module
numbers, the measured tables, the decision rubrics, the two surfaces every command runs on, the
commands from `git clone` to a running benchmark, and the repository and site URLs. Anyone reading
it should be able to rebuild the day's environment without the site. Every number in it comes from
`eval/RESULTS.md` — when the corpus or the code moves, the tables here move with them.

Kraken Air (XX) and Wyvern Overseas Airways (YY) are fictional; the corpus is synthetic training
material and no Amadeus system, customer or production data appears anywhere in this repository.
