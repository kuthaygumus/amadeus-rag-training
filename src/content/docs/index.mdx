## Three things to install — before the day

The whole practical part runs from one small repository you clone, two containers you start, and
a request collection you click through. Install these three at home, on a connection you are not
sharing with twenty other people, and pull the two models while you are there:

| | Why | Get it |
|---|---|---|
| **Ollama** | runs the two models on your laptop — nothing leaves the machine | [ollama.com/download](https://ollama.com/download) |
| **Podman Desktop** | runs ChromaDB and the lab's API as containers | [podman-desktop.io](https://podman-desktop.io) |
| **Bruno** | the request collection that is the day's handout | [usebruno.com/downloads](https://www.usebruno.com/downloads) |

No API key, no cloud account, no sign-in, no Python. [Setup](/modules/00-setup/) walks every step
and ends on one request that says `ready`.

## The rule this course is built on

No concept is introduced before you have **seen the failure that requires it**. Each module opens
on the previous one's wall; module 2 is the one declared exception, and says so on its own page —
it exists to earn one sentence that three later gates spend.

**bare LLM** → *it answers about our airline, confidently, with no source — and it is wrong* →
**what a weight is** → *a weight is a frozen photograph of the training data* → **fine-tuning** →
*we can re-take the photograph with our data — and it is of last quarter, and it cites nothing* →
**the data moved** → *put the whole rule book in the prompt: it fits, and you pay for the whole
book, in tokens and in seconds, on every question* → **simple RAG** → *hand it the right piece:
the answer is grounded — now look at what was actually retrieved* → **ChromaDB** → *the chunks
are visible, and the one with the number has lost its header* → **chunking and noise** → *cut at
the document's own structure: same model, same store, right answer* → **freshness** → *re-ingest
last quarter's edition and this quarter's: 120 → 90 with no retraining* → **closing**.

## How the day runs

Theory modules — how a neural network learns, how a model is trained and fine-tuned — are driven
by the trainer from the projector; there is nothing to run on your laptop for them. Practical
modules send you to **Bruno**: the page names a folder and a request, you run it, and the
response is the lesson. Each request has a *Docs* tab with the gate question and what to look for.

There are exactly three surfaces, and every command fence on this site says which one it belongs
to: **Bruno** (a folder and a request in the `amadeus-rag-lab` collection), a **terminal at the
repository root of `amadeus-rag-lab`** (for `ollama …`, `podman …` and `curl …`), and **Podman
Desktop** (to see the two containers). Retrieval quality numbers — `hit@1`, `recall@5`, `MRR` over
the twenty gold questions — are measured by the trainer with `npm run eval` and quoted on the
pages where they matter; nobody in the room runs a benchmark.

The day is 7 October 2026, 09:00–15:00. Setup is pre-work, done at home the evening before.

Start at [Setup](/modules/00-setup/); every term the day uses is defined once in the
[glossary](/reference/glossary/), and what the day deliberately leaves out — hybrid retrieval,
reranking, agentic RAG — is in [Going further](/reference/going-further/).
